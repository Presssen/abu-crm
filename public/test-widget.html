🧪 Página de Prueba - Widget de Chat ABU

Esta página sirve para probar el widget de chat en un entorno limpio

Este es un sitio web de ejemplo con contenido de prueba. El widget de chat de ABU debería aparecer en la esquina inferior derecha de la pantalla.

✅ Qué verificar:
  • El icono del chat debe ser visible y NO transparente
  • Al hacer clic, la ventana de chat debe abrirse correctamente
  • No debe haber áreas transparentes en el widget
  • El widget debe funcionar en móviles y escritorio
